# Raycast commands

In Raycast: Settings → Extensions → Script Commands → Add Directories, and pick this folder. The commands then appear in Raycast's search ("Capture Text", "Read QR Code", …), and you can give each its own hotkey there.

Each command opens a `textgrabber://` link; see the main README for the full list. Alfred can use the same links with an "Open URL" action.
